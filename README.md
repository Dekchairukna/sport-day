# ระบบกีฬาสี

ระบบจัดการงานกีฬาสีภายในโรงเรียน เขียนด้วย Python + Streamlit ใช้ได้ทั้งคอมพิวเตอร์และมือถือ

## ทำอะไรได้บ้าง

| หน้า | ใช้ทำอะไร | ใครเปิดได้ |
|---|---|---|
| กระดานผล | ถ้วยรวมแต่ละสี ผลล่าสุด ตารางวันนี้ รีเฟรชเองทุก 30 วินาที (เปิดขึ้นจอใหญ่ได้) | ทุกคน |
| ตารางแข่ง | ดูตามวัน · จัดนักกีฬา (กรองรุ่นตามเพศ/ชั้นให้อัตโนมัติ) · เตือนเวลาชน · เพิ่มกีฬาใหม่ · แก้เวลา/ยกเลิกรายการ | ดูได้ทุกคน แก้ต้องมีสิทธิ์จัดตารางแข่ง |
| รายงาน | สรุปถ้วย แยกชนิดกีฬา ผลรายวัน · ดาวน์โหลด PDF และ Excel | ทุกคน (Excel ที่มีรายชื่อต้องมีสิทธิ์สมาชิก) |
| บันทึกผล | เลือกรายการ → กดสีที่ชนะ ใส่สกอร์ · เก็บชื่อผู้บันทึกและเวลา | ตามสิทธิ์ |
| เช็คชื่อ | กดปุ่ม มา/สาย/ลา/ขาด รายคน บันทึกทันที ใช้บนมือถือได้ · รอบประจำวัน (เช้า ประชุมสี · สาย/บ่าย ซ้อมเชียร์) สร้างทีละหลายวันในกดเดียว · ทุกรอบระบุกิจกรรม (เช็ครวมสี ซ้อมเชียร์ ซ้อมขบวนพาเหรด ฯลฯ เพิ่มกิจกรรมใหม่ได้ตอนสร้างรอบ) · เช็คทั้งสี ตามหน้าที่ หรือนักกีฬาตามรายการแข่ง · มา/สาย/ลา/ขาด · สรุปร้อยละการมาแยกกิจกรรมและรายคน | ตามสิทธิ์ |
| สรุปเหรียญ | ตารางเหรียญทอง/เงิน/ทองแดงรายสี (เรียงแบบโอลิมปิก) · แยกชนิดกีฬา · อันดับนักกีฬาและรางวัลพิเศษ (ต้องเข้าสู่ระบบ) | ทุกคน (รายชื่อต้องเข้าสู่ระบบ) |
| เกียรติบัตร | PDF A4 แนวนอน: ผู้ได้เหรียญ เข้าร่วม นักกีฬายอดเยี่ยม ผู้ปฏิบัติหน้าที่ · ตั้งผู้ลงนาม ตราโรงเรียน เลขที่ · ทะเบียนคุม Excel · เลือกนักกีฬายอดเยี่ยมจากอันดับเหรียญ | สิทธิ์เกียรติบัตร |
| ถ้วยรางวัล | เช็คลิสต์ รอเตรียม → ติดสติ๊กเกอร์แล้ว → ส่งครูฟ้าแล้ว · พิมพ์สติ๊กเกอร์ PDF | ตามสิทธิ์ |
| สมาชิก | ชื่อ ชั้น ห้อง สี · หน้าที่ (ประธานสี สต๊าฟ หรีด ขึ้นสแตนด์ ฯลฯ) และรายการแข่ง เลือกได้หลายอย่าง · ไซซ์เสื้อ/ค่าเสื้อ | ตามสิทธิ์ |
| ย้ายสี | เปลี่ยนสีพร้อมเหตุผล เก็บประวัติ · ถอดออกจากรายการที่ยังไม่แข่ง · ถ้วยที่ได้ไปแล้วยังเป็นของสีเดิม | ตามสิทธิ์ |
| ตั้งค่า | ชื่องาน ชื่อโรงเรียน สี หน้าที่ กิจกรรมเช็คชื่อ (แก้ชื่อ ซ่อน ลบ) · นำเข้ารายชื่อและตารางแข่งจาก CSV | ตามสิทธิ์ |
| แผนผังสแตนด์ (ในหน้าสี แท็บ สแตนด์) | 5 แถว x 10 ที่ (ปรับได้ที่ ตั้งค่า → ทั่วไป) · จัดอัตโนมัติจากคนที่มีหน้าที่ ขึ้นสแตนด์ (เรียงชั้น หรือสลับชาย-หญิง) · สลับที่ 2 คน · แก้แบบตาราง · พิมพ์ PDF | สต๊าฟสีของสีนั้น หรือครูที่จัดการทุกสีได้ |
| **หน้าสี** (สีละหน้า) | งานที่ต้องทำ (รายการที่ยังไม่มีนักกีฬา เวลาชน หน้าที่ที่ว่าง ค่าเสื้อค้าง) · นักกีฬาที่ต้องลงแข่งวันถัดไป · จัดนักกีฬาของสี · รายชื่อและแก้ไขสมาชิกในสี · เช็คชื่อ · เสื้อสี | ทุกคนเห็นถ้วยของสี · ทำงานได้ด้วยบัญชีสต๊าฟของสีนั้น หรือครูที่มีสิทธิ์จัดการทุกสี |

กติกาคะแนน: 1 รายการ = 1 ถ้วย สีที่ได้ถ้วยมากกว่าชนะ รายการที่ยกเลิกไม่นับ

### ผู้ใช้และสิทธิ์

แต่ละคนมีบัญชีของตัวเอง (ชื่อผู้ใช้ + รหัสผ่าน) ผู้ดูแลระบบเพิ่ม แก้ไข ลบ ปิดใช้งาน และรีเซ็ตรหัสผ่านได้ที่เมนู **ทะเบียน → ผู้ใช้**

| บทบาท | ทำอะไรได้ |
|---|---|
| ผู้ชมทั่วไป (ไม่เข้าสู่ระบบ) | กระดานผล ตารางแข่ง รายงาน และถ้วยของแต่ละสี ไม่เห็นรายชื่อนักเรียน |
| สต๊าฟสี | หน้าสีตัวเอง: จัดนักกีฬาและแก้สมาชิกในสี · **บันทึกผล** (ผลที่คนอื่นบันทึกแล้ว แก้หรือลบไม่ได้) · **เช็คชื่อสมาชิกในสี** · สองข้อหลังผู้ดูแลระบบเปิด/ปิดได้รายบัญชี |
| ครู/กรรมการ | เลือกสิทธิ์ทีละข้อ: บันทึกผล · จัดตารางแข่งและนักกีฬา · เช็คชื่อ · ถ้วยรางวัล · สมาชิก (รวม Excel ที่มีรายชื่อ) · จัดการหน้าสีทุกสี · ย้ายสี · ตั้งค่า |
| ผู้ดูแลระบบ | ทุกอย่าง รวมถึงจัดการผู้ใช้ |

- เมนูที่ไม่มีสิทธิ์จะไม่แสดง สิทธิ์ที่แก้มีผลทันที บัญชีที่ปิดใช้งานหรือถูกลบจะออกจากระบบเอง
- ต้องมีผู้ดูแลระบบที่ใช้งานอยู่อย่างน้อย 1 คนเสมอ และแก้บทบาทหรือลบบัญชีตัวเองไม่ได้
- รหัสผ่านเก็บแบบเข้ารหัส (PBKDF2) ยาวอย่างน้อย 6 ตัว ใส่ผิด 5 ครั้งต้องรอ 1 นาที
- ทุกคนเปลี่ยนรหัสผ่านของตัวเองได้ที่แถบด้านซ้ายหลังเข้าสู่ระบบ

**ครั้งแรก:** ระบบสร้างบัญชี `admin` ให้ รหัสผ่านคือ PIN ครูเดิม (`edit_pin` ใน secrets หรือ `1234` ถ้าไม่ได้ตั้ง) เข้าแล้วให้เปลี่ยนรหัสผ่านทันที
ถ้าเคยตั้ง PIN สต๊าฟสีไว้ ระบบย้ายเป็นบัญชี `color1`, `color2` … (ตามลำดับสี) ใช้ PIN เดิมเป็นรหัสผ่าน

### สำรองและย้ายข้อมูล

ผู้ดูแลระบบไปที่ **ตั้งค่า → สำรองข้อมูล**: ดาวน์โหลดไฟล์สำรอง (ทุกตารางรวมผู้ใช้) · กู้คืนจากไฟล์สำรอง ·
ย้ายข้อมูลจากไฟล์ SQLite เดิมเข้า PostgreSQL หลังตั้ง `db_url` · ถ้าเว็บบน Streamlit Cloud ยังไม่ได้ตั้ง `db_url`
ระบบจะเตือนสีแดงที่แถบซ้าย เพราะข้อมูลจะหายเมื่อแอปเริ่มใหม่

## ติดตั้งและรันในเครื่อง

ต้องมี Python 3.10 ขึ้นไป

```bash
git clone https://github.com/<ชื่อผู้ใช้>/<ชื่อ-repo>.git
cd <ชื่อ-repo>
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

เปิดเบราว์เซอร์ที่ http://localhost:8501 · ครั้งแรกระบบจะสร้างฐานข้อมูลที่ `data/sportsday.db` และใส่ตารางแข่ง 27 รายการจาก `seed/schedule.csv` ให้

ให้มือถือในวง Wi-Fi เดียวกันเปิดได้: ดูที่อยู่ `Network URL` ที่ขึ้นตอนรัน

### ขั้นตอนแรกหลังติดตั้ง

1. เข้าสู่ระบบที่แถบซ้ายด้วยชื่อผู้ใช้ `admin` รหัสผ่าน `1234` แล้วเปลี่ยนรหัสผ่าน และสร้างบัญชีครูกับสต๊าฟสีที่ **ทะเบียน → ผู้ใช้**
2. **ตั้งค่า → นำเข้าข้อมูล** อัปโหลดไฟล์รายชื่อ CSV (ดาวน์โหลดแม่แบบได้ในหน้านั้น)
3. **ตารางแข่ง → เพิ่ม/แก้รายการ** ตรวจเวลาแข่ง ตารางต้นฉบับมีเวลาลงท้าย .12 ทุกช่อง ให้แก้เป็นเวลาจริง
4. **ตารางแข่ง → จัดนักกีฬา** เลือกนักกีฬาแต่ละรายการ แล้วดูแท็บ **เวลาชน**

## รหัสผ่านเริ่มต้นของ admin

สร้างไฟล์ `.streamlit/secrets.toml` (คัดลอกจาก `.streamlit/secrets.toml.example`)

```toml
edit_pin = "รหัสของโรงเรียน"
```

ไฟล์นี้อยู่ใน `.gitignore` จะไม่ถูกอัปขึ้น GitHub

## อัปขึ้น GitHub

```bash
git init
git add .
git commit -m "ระบบกีฬาสี"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อ-repo>.git
git push -u origin main
```

**ข้อมูลนักเรียนไม่ถูกอัปขึ้น GitHub:** โฟลเดอร์ `data/`, ไฟล์ `.db`, `members*.csv` และ `.xlsx` ถูกกันไว้ใน `.gitignore` แล้ว ถ้า repo เป็นสาธารณะ ตรวจด้วย `git status` ก่อน push ทุกครั้งว่าไม่มีไฟล์รายชื่อติดไปด้วย

## เปิดใช้ออนไลน์ (ให้กรรมการหลายคนกรอกผลพร้อมกัน)

1. สมัคร [Streamlit Community Cloud](https://share.streamlit.io) ด้วยบัญชี GitHub แล้วกด **Create app** เลือก repo นี้ ไฟล์หลัก `app.py`
2. สร้างฐานข้อมูล PostgreSQL ฟรี เช่น [Neon](https://neon.tech) หรือ [Supabase](https://supabase.com) แล้วคัดลอก connection string
3. ในหน้าแอปบน Streamlit Cloud ไปที่ **Settings → Secrets** ใส่

```toml
edit_pin = "รหัสของโรงเรียน"
db_url = "postgresql://user:password@host/dbname"
```

ต้องใช้ PostgreSQL เพราะไฟล์ SQLite บน Streamlit Cloud จะหายเมื่อเซิร์ฟเวอร์รีสตาร์ต

## โครงสร้างโปรเจกต์

```
app.py                  เมนูหลัก
views/                  หน้าจอแต่ละหน้า
sportsday/
  db.py                 ตารางฐานข้อมูล
  services.py           กติกาหลัก: สิทธิ์ลงรุ่น เวลาชน นับถ้วย ย้ายสี เช็คชื่อ
  reports.py            รายงาน Excel/PDF และสติ๊กเกอร์ถ้วย
  ui.py                 การเข้าสู่ระบบ สิทธิ์ผู้ใช้ และสไตล์หน้าจอ
  components.py         ส่วนหน้าจอที่ใช้ร่วมกัน (รายชื่อ จัดนักกีฬา เช็คชื่อ เสื้อสี)

tests/                  ทดสอบกติกาหลัก
```

## รูปแบบไฟล์ CSV

**รายชื่อ:** `ชั้น,ห้อง,เลขที่,เลขประจำตัว,คำนำหน้า,ชื่อ,นามสกุล,เพศ,สี,ค่าเสื้อ,หมายเหตุ`
ตัวอย่าง `ม.1,1,1,0001,เด็กชาย,สมชาย,ใจดี,ชาย,ชมพู,จ่ายแล้ว,` · นำเข้าซ้ำได้ ถ้าเลขประจำตัวตรงกันจะอัปเดตแทนการเพิ่มใหม่

**ตารางแข่ง:** `ชนิดกีฬา,เพศ,ระดับ,รายละเอียด,วันที่,เริ่ม,นาที,สนาม`
เพศ = ชาย/หญิง/ผสม · ระดับ = ต้น/ปลาย/รวม · ตัวอย่าง `กรีฑา,ชาย,ต้น,100 ม.,2026-11-12,13:00,20,ลู่กรีฑา`
